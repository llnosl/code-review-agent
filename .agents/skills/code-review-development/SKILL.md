# 开发与学习要求

项目文档：https://ucneo24atg7t.feishu.cn/wiki/LfZUwCoRFi4dJ4kNaRUcAEgKnEg

## 开发流程

每个开发步骤严格按顺序执行：

1. 在对话中给出本步设计，不修改代码。
2. 等待用户检查并明确确认设计。
3. 通过飞书 CLI 将已确认设计写入设计文档对应章节，不随意追加到其他位置。
4. 读取并核对飞书写入的位置和内容。
5. 核对成功后，按已确认设计实现本步代码。
6. 完成后说明改动文件、实现内容和验证结果；未验证项如实说明。

飞书写入或核对失败时，停止本步并说明具体原因；成功写入并核对前，不得继续实现代码。

## 实施约束

- 小步推进，一次只处理一个明确步骤；每次生成代码不得超过 300 行。
- 接手项目时，先阅读项目文档及其子文档、仓库代码，了解目标和开发进度；继续开发前核对相关上下文。
- 先检查本机环境和依赖，不假定数据库已安装；需要安装或调整环境时，先说明并征得确认。
- 讲解、提问和讨论不代表授权修改代码。

## 学习讲解

- 使用简洁易懂的中文，一次讲一个小步骤，不一次展开大量内容。
- 讲清楚做了什么、为什么这样做、其中的设计；新术语先解释。
- 结合仓库实际代码讲解，关键点附可点击的绝对文件路径和行号。
- 复杂流程可用简图辅助，避免堆砌概念和无关描述。
